# Serentha Villas Manager - Ücretsiz PWA V5

Mac ve Apple Developer üyeliği olmadan kullanılabilir.
GitHub Pages üzerinde yayınlanabilir ve iPhone Safari'den Ana Ekrana Ekle ile kurulabilir.

Not: Web/PWA bildirimleri iOS'ta native uygulama kadar güvenilir değildir. Uygulama açıkken zamanlı kontrol yapılır. Uygulama tamamen kapalıyken kesin zamanlı bildirim gerekiyorsa native iOS + Apple Developer gerekir.

GitHub Pages:
1. Repository oluştur.
2. Bu klasördeki index.html, manifest.json, sw.js dosyalarını root'a yükle.
3. Settings > Pages > Deploy from a branch > main > / (root).
4. Sayfayı iPhone Safari'de aç.
5. Paylaş > Ana Ekrana Ekle.
